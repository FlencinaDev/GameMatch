# 🎮 GameMatch

> **Sistema inteligente de recomendación de videojuegos**

GameMatch es un proyecto desarrollado para el **Trabajo Práctico Integrador de UTN**, cuyo objetivo es crear un sistema capaz de analizar las preferencias y características de un jugador para recomendarle videojuegos acordes a su perfil.

---

## 🧠 ¿Cómo funciona?

El sistema recopila diferentes datos del jugador, como:

* 🎂 Edad
* 🎮 Experiencia jugando
* ⏱️ Tiempo disponible
* 👥 Cantidad de jugadores
* ⚔️ Dificultad deseada
* 💰 Presupuesto
* 🎭 Género preferido
* 😊 Estado de ánimo
* 💻 Plataforma

A partir de esta información, **GameMatch aplica un conjunto de reglas y cálculos** para determinar qué tipo de experiencia puede adaptarse mejor al jugador.
